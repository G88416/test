    Bulk Import Students
    File Format Instructions

    Upload a CSV or Excel file with student data. Two formats are supported:

    Format 1: Detailed Format (16 columns)
    surname,firstname,gender,grade,class,cell,email,language,father_firstname,father_surname,father_email,father_cell,mother_firstname,mother_surname,mother_email,mother_cell

    Example:

    Mandela,Nelson,Male,10,10A,0821234567,nelson@example.com,English,John,Mandela,john@example.com,0827654321,Mary,Mandela,mary@example.com,0828765432
    Format 2: Simplified Format (7 columns)
    number,grade,accession_no,name,surname,class,teacher

    Example:

    1,10,2024001,Nelson,Mandela,10A,Mr. Smith

    Note: Gender should be "Male" or "Female". Grade should be 1-12 or Grade R-Grade 12.

    CSV Format Instructions

    Upload a CSV file with the following columns (in order):

    student_id,student_name,subject,grade,comment

    Example:

    1,John Doe,Mathematics,85,Excellent work
    1,John Doe,English,78,Good progress
    2,Jane Smith,Mathematics,92,Outstanding

    Note: Grades should be 0-100. Make sure the class and term are selected before importing.
